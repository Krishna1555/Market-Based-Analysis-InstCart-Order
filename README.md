# Instacart Market Basket Analysis

Analyzed 3 million grocery orders from 200,000+ users to uncover purchasing patterns, segment customers, and predict product reorders using machine learning.

### Key Features
- Applied **PCA and K-Means clustering** to identify five distinct customer segments.
- Used the **Apriori algorithm** to discover product associations and identify 28 high-value product pairs for cross-selling.
- Developed **CatBoost and Neural Network models** to predict customer reorders using feature engineering and classification techniques.

### Tech Stack
Python | Pandas | NumPy | Scikit-learn | CatBoost | Mlxtend | Matplotlib | Seaborn

### Objective
Leverage customer purchase data and predictive analytics to improve product recommendations, personalized marketing, and cross-selling strategies.
